# Установка GET-Passes на Windows

## Рекомендуемый вариант — Setup.exe

1. Откройте GitHub Releases.
2. Скачайте `GET-Passes-Setup.exe` из нужного релиза.
3. Если для релиза настроена цифровая подпись, проверьте свойства файла → «Цифровые подписи» и убедитесь, что подпись действительна.
4. Запустите установщик от имени пользователя с правом установки программ.
5. По умолчанию приложение устанавливается в `Program Files\GET-Passes` и создаёт ярлык в меню «Пуск». Ярлык на рабочем столе можно включить в мастере установки.

Python на рабочем компьютере не требуется.

## Где находятся рабочие данные

Программа и данные разделены. При установке в `Program Files` рабочие файлы находятся в пользовательском каталоге:

```text
%LOCALAPPDATA%\GET-Passes
```

Там находятся `gup.sqlite3`, `settings.json`, `photos\`, `backups\` и журнал сбоев. Обычное удаление приложения **не должно удалять эти рабочие данные**.

Перед переносом ПК или переустановкой Windows создайте резервную копию средствами приложения.

## Обновление

Новый Setup.exe можно запускать поверх предыдущей версии. Inno Setup использует постоянный `AppId`, поэтому обновление воспринимается как новая версия того же приложения, а не как второе отдельное приложение.

Перед обновлением рекомендуется:

1. завершить GET-Passes;
2. создать резервную копию;
3. установить новую версию;
4. выполнить короткую проверку запуска и печати.

## Удаление

Используйте Windows Settings → Apps либо пункт удаления GET-Passes. Установщик удаляет файлы программы и ярлыки. Пользовательская БД, фотографии и резервные копии в `%LOCALAPPDATA%\GET-Passes` сохраняются.

## Portable ZIP

`GET-Passes-windows.zip` остаётся альтернативой установщику. Portable-вариант удобен для тестирования или запуска без установки, но при эксплуатации рекомендуется Setup.exe: он даёт стандартную регистрацию программы в Windows, ярлыки и корректный uninstall.

## Приёмка

Перед вводом новой версии в работу выполните `docs/ACCEPTANCE.md`. Автоматический Windows CI проверяет сборку/установку/запуск/удаление, но физическую печать на конкретном принтере необходимо подтвердить вручную.
