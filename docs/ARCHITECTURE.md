# Расширение приложения Python/Tkinter

`getpass_ui.tasks.run_task` запускает операцию в отдельном потоке. Окно
ожидания использует очередь и `after`; рабочий поток не обращается к Tkinter.
Файловые диалоги и чтение полей выполняются до запуска. Для ручного дуплекса
подтверждение передаётся через очередь в главный поток. Импорт поддерживает
кооперативную отмену между страницами, атомарный PDF сохраняет прежний файл.
После передачи задания принтеру отменять его следует в очереди Windows.

Навигация регистрируется в `getpass_ui/navigation.py` через `Section`.
Новый раздел добавляется в реестр без изменения построителя меню `App`.
Существующие формы остаются вкладками; разделы журнала и обслуживания
открываются через общее меню.

Миграции находятся в `getpass_core/migrations.py`: версии 1–2 описывают
историю событий, версия 3 добавляет таблицу выдач и индексы. Они выполняются
в транзакции инициализации журнала. База более новой версии отклоняется до
изменения схемы. При исключении соединение закрывается с откатом.

Автоматическое перезаписывание БД при произвольной ошибке отключено:
блокировка и повреждение не должны приводить к потере актуальных записей.
Восстановление выполняется через проверенный архив и существующий диалог.
Файл `.healthy` от предыдущей версии сохраняется, но автоматически не применяется.
