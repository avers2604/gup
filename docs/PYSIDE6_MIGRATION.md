# Оценка перехода на PySide6

`getpass_core` не зависит от Tkinter: хранение, печать, рендеринг, резервные
копии и импорт можно переиспользовать. Переписывать потребуется только
`getpass_ui`, точку входа и сборочные настройки.

Переход даст полноценные accessibility API Qt, более функциональные таблицы,
виртуализацию больших журналов и устойчивое DPI-масштабирование. Цена —
переписывание форм, диалогов, журнала, кадрирования и темы, увеличение EXE,
новая зависимость PySide6 и повторная проверка печати на Windows.

Рекомендуемый следующий шаг — отдельный прототип окна журнала на PySide6 с
замером доступности, скорости фильтрации и размера сборки. Полная миграция
ориентировочно займёт 2–3 недели и нужна только если эти показатели заметно
лучше текущего Tkinter-интерфейса.
