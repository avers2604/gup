# Переход на PySide6

> Статус: предварительная оценка заменена утверждённым архитектурным design-spec.

Актуальная стратегия миграции GET-Passes 2.0 находится в:

`docs/superpowers/specs/2026-09-11-pyside6-v2-ui-design.md`

Ключевое принятое решение: Python + PySide6 + MVVM-lite + существующий
`getpass_core` + SQLite + существующий renderer. Миграция выполняется
поэтапно рядом с рабочим Tkinter-интерфейсом; внешний вид печатных пропусков
и бейджей не изменяется.
